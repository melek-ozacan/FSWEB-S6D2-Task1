# Gün Projesi: Component'lere Prop Gönderme

Yöneticin, seni intagrasram clone olan bir uygulama takımına aldı. Bu takımda projenin bazı görevlerini sen yapacaksın.

Projede AramaCubugu ve Gonderiler componentleri var.
İlk olarak bu componentleri App.css'de, ihtiyacı olan propları gönderecek şekilde kullanacaksın.

- Öncelikle, uygulamanın yapısına bir göz atarak başlayabilirsin.
- sonra AramaCubugu ve Gonderiler componentlerine göz atıp hangi prop'ları aldığını ve kullandığına bakabilirsin.
- App.js'de bu componentleri import ettikten sonra kullanabilirsin.
